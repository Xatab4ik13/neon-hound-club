# HOUND HUNT: лендинг + шоу + админка (только фронт)

Всё на моках и локальном стейте. Бекенда не касаемся.

## 1. Один роут, два режима

`/club/hound-hunt` получает тумблер сверху: **Лендинг ↔ Шоу**.

- Компактная плашка в шапке (в стиле dev-контролов скорости), видна всегда пока фича в разработке — потом убираем одной константой `HH_DEV_TOGGLE = true`.
- Текущий код шоу выносим из `club.hound-hunt.tsx` в `src/components/club/hound-hunt/HuntShow.tsx` без изменений логики.
- Новый `src/components/club/hound-hunt/HuntLanding.tsx` — продающая страница.
- Роут становится тонкой оболочкой: режим + тумблер.
- Доступ только в PWA: если не standalone-режим — экран «Открой в приложении» (используем существующую проверку PWA, если её нет — `matchMedia("(display-mode: standalone)")`).

## 2. Лендинг (продающая страница)

Порядок блоков сверху вниз, всё в нашем стиле: чёрный фон, магента `--primary`, ядовитый зелёный `#B6FF3C` для акцентов охоты, `font-display` заголовки, лёгкие радиальные свечения и появление по скроллу.

1. **Герой**: персонаж (3D, анимация Agree Gesture, та же что в финале шоу) + заголовок «HOUND HUNT» + подзаголовок «Гончая спускается раз в неделю». Только для Hell Pass Platinum — бейдж.
2. **Таймер до старта**: крупный отсчёт дни/часы/минуты/секунды. Состояния:
   - `soon` — тикает таймер + кнопка «Напомнить» (пока просто toast);
   - `live` — «ОХОТА ИДЁТ» пульсом + кнопка «Войти в шоу» (переключает в режим Шоу);
   - `finished` — «Охота завершилась», результаты прошлой охоты (аватарки победителей + призы) и таймер до следующей.
3. **Призы этой недели**: карточки из `HUNT_PRIZES` — «столько призов, столько раундов».
4. **Как участвовать** (3 шага): купи Hell Pass Platinum → набери билеты → зайди в назначенное время.
5. **Капсулы = шансы**: наглядный калькулятор. Порог участия (например 10 билетов) = 1 капсула, 20 = 2, 30 = 3. Слайдер билетов показывает, сколько твоих аватарок будет крутиться в барабане.
6. **Почему так называется**: короткий лор — гончая выбивает лишних, последний забирает приз.
7. **Витрина Hell Pass**: акцент на Platinum, кнопка ведёт на `/club/hell-pass`. Плюс блок «купить билеты» → магазин.
8. **FAQ** (аккордеон): что если не зайду вовремя, честность розыгрыша, что с билетами после охоты.

Новых анимаций через Meshy не делаем — используем уже загруженную `rider-agree.glb`.

## 3. Шоу: раунды из конфига

Число раундов = число призов из конфига (сейчас 3). Порог билетов из конфига определяет `slots` участника (капсулы = аватарка × N в барабане). Логика подмены победителя: если в конфиге для приза задан конкретный участник — `pickWinner` возвращает его, иначе честный случайный выбор по весам.

## 4. Админка на фронте: `/admin/hound-hunt`

Новый роут в стиле остальных админ-страниц, весь стейт локальный (`useState` + localStorage), без API:

- **Дата и время старта** охоты (datetime-local) — это то, что видит таймер лендинга.
- **Порог билетов за одну капсулу** (число).
- **Призы**: список с добавлением/удалением/сортировкой (место, название, картинка-URL). Кол-во призов = кол-во раундов, показываем это подсказкой.
- **Победитель для каждого приза**: селект «Честный розыгрыш» или конкретный участник из списка (реальные ники из `fetchHuntEntries`).
- Кнопка «Применить к шоу» — записывает конфиг, шоу и лендинг его читают.

Конфиг живёт в новом `src/components/club/hound-hunt/hh-config.ts`: тип `HuntConfig`, дефолт из текущих моков, чтение/запись в localStorage, хук `useHuntConfig()`.
