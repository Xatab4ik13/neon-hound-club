# Hound Hunt: честный удар и стабильные ники

Две проблемы, обе от одной причины — лента живёт в «циклическом» массиве с пересборкой состава, а удар происходит вслепую.

## 1. Удар только по живой капсуле

Сейчас: 3D-персонаж бьёт по своему таймеру, а мы уже после импакта смотрим, кто оказался в центре. Если там дырка — удар в пустоту.

Меняем управление на обратное: **лента задаёт ритм, персонаж подстраивается.**

- Лента едет непрерывно, как сейчас.
- Каждый кадр считаем, через сколько мс в центр придёт **следующая живая** капсула (дырки пропускаем).
- Известна задержка от запуска взмаха до кадра импакта (в `RiderScene` импакт на 60% клипа). За `impactDelay` мс до прихода живой капсулы запускаем одиночный взмах (`kick()` вместо `loopKick`).
- Импакт-callback больше не «ищет» цель: цель уже забронирована при запуске взмаха. Промаха физически не бывает.
- Между взмахами гончая играет idle/бег — визуально она не молотит воздух.

Побочно уходит вся защита от двойных callback: бронь одна на взмах.

## 2. Дырки должны уезжать и не возвращаться

Сейчас окно ленты берёт слот по `index % n`, поэтому дырка, уехав влево, **снова появляется справа**, а при удалении слота из массива мы пересчитываем `reelPhase` — и все ники на кадр сдвигаются. Это и есть «25-й кадр».

Меняем модель ленты на **бесконечную очередь без modulo**:

- Держим `tape: Slot[]` и `tapeOffset` (сколько элементов уже срезано слева).
- Позиция на экране = абсолютный индекс, `key` слота = его собственный `sid`, а не позиция в окне. Контент DOM-узла никогда не подменяется → мерцания ников нет.
- Живые участники добираются в хвост очереди по кругу (тасуем порядок каждый круг), дырки в хвост **не** добираются — они одноразовые и существуют только пока едут к левому краю.
- Ушедший за левый край слот удаляем с головы и увеличиваем `tapeOffset` на столько же. `reelPhase` не трогаем — скачка нет by design.

## 3. Заодно

- Убираем `SWEEP_AT` и остатки логики «схлопывания» — они больше не нужны.
- Счётчик «осталось N» считаем по живым в pool, а не по слотам ленты.

## Технически

Файлы: `src/routes/club.hound-hunt.tsx` (модель ленты + планировщик удара), `src/components/club/hound-hunt/RiderCharacter.tsx` / `RiderScene.tsx` (одиночный `kick()` по команде + экспорт `impactDelay`), `ReelStage` внутри страницы (окно по абсолютным индексам, key по `sid`).

Проверю покадрово в браузере: каждый взмах попадает по аватарке, дырка уезжает влево и исчезает, ники за весь прокрут не дёргаются.
